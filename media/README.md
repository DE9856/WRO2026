# media/ — placeholders for required submission assets

WRO §7 requires photos of the vehicle and YouTube links showing
autonomous driving. None of this can be produced remotely — it needs
your physical robot and a camera pointed at it. This folder exists so
the *checklist* is complete and the repo structure is ready; the actual
media is still on you.

## Photos (`media/photos/`)

WRO §7 requires: **"Photos of the vehicle (from every side, from top and
bottom), and a team photo."** Required files (replace these placeholder
names with real ones once you have the images — keep the naming scheme
or update the links in `readme.md` / `docs/index.html` to match):

- [ ] `photos/front.jpg`
- [ ] `photos/rear.jpg`
- [ ] `photos/left.jpg`
- [ ] `photos/right.jpg`
- [ ] `photos/top.jpg`
- [ ] `photos/bottom.jpg` — judges specifically check this one for
      drivetrain compliance (rule 11.3–11.5: driven wheels physically
      coupled, no electronic differential, no omni/ball-caster wheels).
      Take it clearly — this is a common point of question at check time.
- [ ] `photos/team.jpg`

Tips that avoid re-shoots:
- Plain, uncluttered background so judges can actually see the vehicle.
- Even, non-glaring light — outdoor shade or diffuse indoor light beats
  direct flash (also just makes for a better documentation photo).
- Fill the frame — a robot that's a small speck in a big photo is not
  useful for a plagiarism/compliance check (rule 3.7/11.3).

## Video (`media/VIDEO_LINKS.md`)

WRO §7 requires: **one YouTube URL per challenge (Open, Obstacle), each
showing autonomous driving for at least 30 continuous seconds**, public
or accessible-by-link. See `media/VIDEO_LINKS.md` in this folder for the
placeholder fields — fill in the two URLs once you've recorded and
uploaded them, then link them from `readme.md`.

## What NOT to do

Don't fabricate placeholder images or fake URLs that look real — an
unreachable/fake link at submission time is worse than an honest gap,
and judges will check. Leave the checkboxes above unchecked and the
URL fields as `TODO` until the real assets exist.
